# Doctor Portfolio

A premium animated doctor portfolio built with Next.js, React, and custom CSS animations.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Personalize later

Most visible content is kept directly in `app/page.tsx` so it is easy to replace:
- Doctor name and specialty
- Bio
- Experience and education
- Statistics
- Expertise/services
- Publications
- Appointment/contact information
- Doctor portrait

The current portrait is a CSS placeholder, so no external image asset is required to start.
